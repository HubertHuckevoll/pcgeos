BbxBrow Image Recognition Test

This is an HTML 4.01 test page. A supported image displays a green, blue, and orange test pattern. Unsupported or deliberately invalid cases should fail cleanly without stopping the page.

Supported extension cases

Case File Expected result Image
JPEG standard extension image.jpg Displayed as image/jpeg
JPEG long extension image.jpeg Displayed as image/jpeg
JPEG alternate extension image.jpe Displayed as image/jpeg
JPEG JFIF extension image.jfif Displayed as image/jpeg
JPEG mixed-case extension upper.JPEG Displayed as image/jpeg
GIF image.gif Displayed as image/gif
PNG image.png Displayed as image/png
PNG mixed-case extension upper.PNG Displayed as image/png

Magic-byte sniff cases

These files contain valid image data but use a .bin extension. They test magic-byte recognition only when this page is fetched through HTTP and the server returns an empty or ambiguous MIME type such as application/octet-stream. A local file: URL uses the extension path and is not expected to sniff these files.

Signature File Expected over HTTP Image
JPEG FF D8 FF jpgmagic.bin Displayed as image/jpeg
GIF89a gifmagic.bin Displayed as image/gif
PNG signature pngmagic.bin Displayed as image/png

Unsupported format cases

These are valid files in formats not currently supported by the BbxBrow image import path. They should show their alternate text or a broken-image placeholder, and the rest of the page should continue loading.

Format File Expected result Image
WebP image.webp Not displayed; page remains usable
SVG image.svg Not displayed; page remains usable

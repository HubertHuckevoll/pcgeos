# ISUI 2000

ISUI 2000 is a separate specific UI library based on ISUI. It contains the
Windows 2000 style changes: flat toolbar buttons with hover borders, softer
button and menu edges, thinner dialog palette bevels, grey group-box etching,
and softer document borders. Original ISUI keeps its existing appearance.

## Selection

Choose ISUI 2000 in the UI preferences. It uses the ISUI desktop, taskbar and
font defaults. Changing the UI combo also selects its default colour scheme:
Motif Default for Motif, ISUI Default for Industry Standard, Meadows for Motif
Redux, and ISUI 2000 Default for ISUI 2000. On 16-colour displays, Motif Redux
uses Motif Default and ISUI 2000 uses ISUI Default. Monochrome displays keep
colour settings unchanged.

Changing only the scheme does not change the UI library, desktop or fonts.
You can choose a UI combo, then choose a different scheme before applying.
Opening/resetting preferences or clicking the current UI retains custom colours.

For manual configuration, set the [ui] specific key to "ISUI 2000" in a normal
build, or "EC ISUI 2000" in an error-checking build. Install the matching
isui2000.geo or isui2000ec.geo library. Changing the specific UI requires a
restart.

## Default colours

ISUI 2000 uses a navy-to-light-blue active title gradient, grey inactive
captions, lighter grey control faces and navy selections. The defaults use
existing GEOS palette entries: (0,51,102), (153,204,255) and (204,204,204).
These approximate the classic Windows colours documented by Microsoft:
[Theme File Format](https://learn.microsoft.com/en-us/windows/win32/controls/themesfileformat-overview#control-panelcolors-section).

Saved colour settings continue to override the library defaults. Changing to
the ISUI 2000 combo selects its matching preset. You can also select "ISUI 2000
Default" in the colour schemes list to apply only the palette. The preset also uses white folder backgrounds and
pale yellow help backgrounds. As with other extended-palette presets, it is
listed on displays with at least 256 colours. "ISUI Default" is unchanged.

## Widget geometry

Text command buttons prefer 50 by 14 dialog units, calculated from the current
UI font through VisConvertSpecVisSize. Larger monikers still determine the
natural size. GEOS then applies parent expansion/clipping and application size
hints through the existing button geometry path. Menus, toolbars, caption
controls, unbordered triggers and graphic-only buttons keep their own sizing
paths. Command monikers use consistent centering in geometry and drawing.

Default-capable buttons reserve a one-pixel ring separately from their normal
content padding. Default and non-default reply buttons use the same content
insets, so changing the default action does not change their natural size.

Normal single-line text fields and drop-downs use four-pixel vertical insets,
including the frame. Framed numeric controls reserve the corresponding space
in their default desired height and use native text centering. Explicit text
field fixed/maximum heights retain legacy margins; width-only hints allow the
new margins. Existing pen, CGA, multi-line text and slider paths are retained.

## Sources and build

Library/SpecUI/ISUI2000 contains the library definition and small manager
wrappers. They include CommonUI directly and reuse ISUI's window and scrollbar
sources. Appearance changes in shared code use _ISUI2000. The ISUI2000 build
flag enables both _ISUI2000 and the existing _ISUI behaviour in ESP and UIC.

Create Installed/Library/SpecUI/ISUI2000 for a new build tree. Run mkmf there,
then pmake depend and pmake full. The normal and error-checking outputs are
isui2000.geo and isui2000ec.geo. The production product file tree includes both
ISUI variants; demo builds continue to use their existing demo specific UIs.
The top-level Ensemble build includes the isui2000 target. Packaging converts
isui2000ec.geo to the DOS filename isui200e.geo, retaining its GEOS long name
"EC ISUI 2000". If the selected library is missing, GEOS falls back to Motif
while the separately saved font settings still apply.

Run perl Library/SpecUI/CommonUI/tests/toolbar-hover.pl from the source root
for the paint, hover, widget geometry and Express menu checks. These checks
do not run PC/GEOS.

Run perl Library/Pref/ConfigUI/tests/specui-selection.pl to check the selection
mapping and build/package registration. Pass a runtime directory as an optional
argument to check that its selected library is present in SYSTEM.
